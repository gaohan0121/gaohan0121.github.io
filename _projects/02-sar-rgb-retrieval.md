This project explores cross-modal representation learning between SAR and RGB/optical images. It addresses differences in imaging mechanisms and appearance by combining multimodal alignment with structure-aware feature extraction for elongated targets such as ships.

## Methods

- CLIP-based alignment
- Contrastive learning
- Strip-convolution features
- Cross-modal feature fusion

## Contributions

- Reviewed recent cross-modal retrieval methods and analyzed design choices.
- Implemented structural modules on top of a baseline retrieval model.
- Explored CLIP-based semantic alignment across sensor modalities.
- Trained models, tuned parameters, and conducted controlled comparisons.
